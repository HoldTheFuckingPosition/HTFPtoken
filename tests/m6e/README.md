# M6E finite actual CLI campaign

The standalone runner imports no product or old module. It authenticates the
frozen270-case oracle component/union and all twelve sealed design pins, exact
input bytes and full expected raw stdout/stderr/exit. C129 obligations are
aliases; G16 are separate actual calls, including repeated inputs. Another125
explicit calls cover source/precedence/IO boundaries. No smoke, help or public
helper invocation supplements the plan.

Run once from `/home/jerem/htfp` after the explicit S137 handoff:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B tests/m6e/run.py author-001
```

Every target call is a fresh `python3 -B -m htfp_accounting_state` subprocess.
Before creating the child, Journal.start appends, flushes and fsyncs its
ATTEMPT_STARTED. Standard RUN_STARTED/ATTEMPT_STARTED/ATTEMPT_FINISHED/
RUN_FINALIZED journals include role/run_id/attempt and cumulative counts.
`ledger.scan(root)` counts every prior start and rejects malformed/unfinalized
campaigns; `Journal(folder,run_id,role,prior)` provides start/finish/finalize.
The ledger is stdlib-only, independent of the product. ROOT's recorder may use
the same minimal events with its own implementation and extra metadata.

The campaign retains final source snapshots, exact per-case input files,
losslessly compressed raw outputs, argv/PYTHONPATH/IO setup, isolated profile
copies and hashes. Copied Python bytes always equal the sealed original;
only the described profile dependency differs. Directory IO fixtures contain
a retained marker with actual kind/path/hash; it is not profile/account data.
The FIFO case creates an anonymous pipe, fstats it as FIFO, closes its writer
before child invocation, passes stdin readfd at /proc/self/fd/0, then closes
the read descriptor. There is no persistent special file or symlink.

An unexpected mismatch, infrastructure problem or source change stops the
campaign and preserves the generation for ROOT reporting before any correction
or retry. Expected negative exits matching the oracle are successful checks.
All generations/attempts remain cumulative; no hidden retries, overwrites or
reset. A passed complete campaign is not repeated without a new concern.

S137's verification budgets are author source/tests/evidence1.5MiB, allM6E4MiB,
free floor2GiB and hard1024 external calls per role across every generation.
These are agent campaign controls and do not restrict future product use.
Only one campaign runs at a time. ROOT's distinct270-call capture/raw audit
starts after the author's seal and stop, then exact independent Review.

Coverage is finite, deterministic and constructive with independent full
reports/literal offsets. No PBT dependency, shrinking, exhaustiveness, native
reachability or public/current-state proof is claimed. New HTTP/native/network,
blockchain, build, install, key, signing and deployment operations remain zero.
