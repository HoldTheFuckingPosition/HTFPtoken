# Selected public evidence records

The public source snapshot includes selected original completion/review/checkpoint records for the manual LGE, integrated fee lifecycle and interrupted BothToken processing work. It also includes offline API/client/tool contracts and documentary input examples.

These records were produced against the complete retained development archive. Most raw transaction/binary/capture bundles and internal handoffs are not included. References to omitted paths remain original archival references. The public snapshot therefore provides summary/provenance records, not a complete native reproduction bundle.

Read [current status](../docs/STATUS.md) for the distinction between bounded local results, the retained computation-error mismatch, and outstanding integration/deployment gates. Review by another development agent is not a professional third-party security audit.
